# TaskBridge Project Memory

- 2026-06-10: CLI output unification is tracked under `openspec/changes/taskbridge-cli-output-polish/`, not ad hoc docs. The change defines `internal/clioutput` as the ordinary-command projection/renderer contract for summary/json/agent/events/explain, with default human CLI chrome in English and machine fields stable English.
- 2026-06-10: `taskbridge analyze priority` is the first stats-panel acceptance example. Default human output renders a boxed stats panel with Urgent/High/Medium/Low/No priority rows and a `Total | Active | Completed` footer; legacy `--format json` remains parseable while global `--json` uses envelopes where routed through projections.
- 2026-06-10: `taskbridge agent *` remains separate from ordinary command `--agent`; it keeps `taskbridge.agent-result.v1` JSON. Ordinary command `--agent` is low-token key=value output via `internal/clioutput`.
- 2026-06-10: CLI output polish final contract: ordinary commands keep default human/table/summary output even when piped; explicit `--json` uses `internal/clioutput` envelopes, `--agent` uses key=value, unsupported `--events` returns an error, and `--explain` renders reviewable Conclusion/Evidence/Risks/Next sections. `list`, `lists`, `config show`, `config validate`, and `analyze` are routed through this global-mode dispatcher.
- 2026-06-10: User-facing CLI chrome should be English. Task tables use English headers/status/quadrant/priority labels; control-plane today/next/inbox/review titles and reasons are English; Feishu provider display name is `Feishu Tasks`; human status labels may include icons but machine output must not.
