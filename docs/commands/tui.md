# tui 命令

`taskbridge tui` 启动交互式终端界面，用于在终端中浏览和操作任务。它提供可视化的任务列表、状态切换和快速操作能力。

## 什么时候用

适合用 `tui` 的情况：

- 想在终端中以交互方式浏览和操作任务。
- 不想记住具体命令，偏好可视化界面。
- 想快速查看和切换任务状态。

不适合用 `tui` 的情况：

- 脚本和 CI 环境：使用对应普通命令 help 中声明的 `--format json` 或命令专属机器输出。
- Agent 自动化：用 `agent` 子命令。
- 只需要快速查看：用 `today` 或 `next`。

## 子命令

`tui` 当前没有子命令。

## 常用流程

```bash
taskbridge tui
```

启动后可使用键盘导航任务列表，查看详情，切换完成状态等。

## 输出模式

- TUI 是交互式界面，不作为脚本机器输出入口。
- Agent 和 CI 不应依赖 TUI 输出。

## 边界

- TUI 写入必须走 storage/service 边界，不能吞掉持久化错误。
- 删除、完成、撤销等操作需要清晰 UI 状态和错误反馈。

## 常见错误

| 错误 | 原因 | 处理 |
| --- | --- | --- |
| 终端不支持 TUI | 终端不兼容 bubbletea/lipgloss。 | 使用普通命令或更换终端。 |
| 中文显示乱码 | 终端编码不是 UTF-8。 | 设置 `export LANG=en_US.UTF-8`。 |

## 最短可用流程

```bash
taskbridge tui
```
